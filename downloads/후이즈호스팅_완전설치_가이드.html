💾 다운로드하기

✅ 모든 설정이 자동화된 올인원 패키지

🎯 이 패키지의 특별함:
• 복잡한 코딩 없이 FTP 업로드만으로 완성
• 후이즈 호스팅에 최적화된 설정
• 데이터베이스 자동 생성 스크립트 포함
• 검색 기능이 완전히 작동하는 상태

1️⃣ 기존 파일 완전 삭제

FTP에서 public_html 폴더의 모든 파일을 삭제하세요.

⚠️ 주의: 기존 웹사이트 파일들이 모두 삭제됩니다. 백업이 필요하다면 미리 받아두세요.

2️⃣ 새 파일 전체 업로드

압축을 풀어서 나온 whois_ftp_complete 폴더 안의 모든 내용을 public_html에 업로드하세요.

업로드 후 구조: public_html/ ├── index.html ← 메인 페이지 ├── assets/ ← CSS, JS 파일들 ├── api/ ← 백엔드 API ├── .htaccess ← ⭐ 중요! 반드시 업로드 ├── database_setup.sql ← 데이터베이스 설정 └── 🚀_후이즈호스팅_설치가이드.md

3️⃣ 데이터베이스 생성 (cPanel)

후이즈 cPanel → 데이터베이스 → MySQL 데이터베이스

  • 데이터베이스 이름: idopress
  • 사용자명: idopress_user
  • 비밀번호: idopress123
  • 권한: 모든 권한 부여

4️⃣ 데이터베이스 테이블 생성

cPanel → phpMyAdmin → idopress 데이터베이스 선택 → SQL 탭

database_setup.sql 파일의 내용을 복사해서 붙여넣기 후 실행

✅ 성공 메시지: "데이터베이스 설정이 완료되었습니다!"

5️⃣ Python 앱 설정

cPanel → 소프트웨어 → Python App → 애플리케이션 생성

Python version: 3.8 또는 3.9 Application root: api Application URL: (비워두기) Application startup file: app.py

패키지 설치: Flask, Flask-SQLAlchemy, PyMySQL 등 자동 설치
