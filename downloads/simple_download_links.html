🎯 검색 기능 사용법

  • 텍스트 검색: 메인 페이지 검색창에서 "춘향", "홍길동" 등 입력
  • 장르별 찾기: "문학", "역사" 버튼 클릭으로 분류별 검색
  • 페이지 이동: 하단 페이지 번호로 다음/이전 페이지 탐색
  • 검색 초기화: "전체보기" 버튼으로 검색 해제
