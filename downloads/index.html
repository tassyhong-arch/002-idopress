🔧 배포 가이드

  1. 다운로드: 위의 최신 완성 버전 다운로드
  2. 압축 해제: tar -xzf idopress_complete_website_final.tar.gz
  3. 업로드: complete_idopress_final/ 폴더 내용을 웹서버 루트에 업로드
  4. 권한 설정: chmod -R 755 *
  5. 확인: 웹사이트 접속하여 디자인 적용 확인
