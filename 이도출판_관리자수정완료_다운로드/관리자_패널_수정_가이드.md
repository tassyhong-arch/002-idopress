# 🔧 관리자 패널 업로드 기능 수정 가이드

## 문제점
- 직접 입력한 이북이 전체 도서목록에 표시되지 않음
- 파일 업로드 시 오류 발생

## 해결책

### 1. 백엔드 수정사항 (✅ 완료)
- Flask app.py에 관리자 전용 API 엔드포인트 추가
- 파일 업로드 기능 구현
- 데이터베이스 스키마 업데이트

### 2. 설치 과정

#### A. 기존 사이트가 이미 설치된 경우

1. **데이터베이스 마이그레이션 실행**
   - cPanel → phpMyAdmin 접속
   - 해당 데이터베이스 선택
   - `database_migration.sql` 내용을 복사해서 실행

2. **Flask 파일 업데이트**
   - 기존 `api/app.py` 파일을 새 버전으로 교체
   - 또는 FTP로 새 파일 업로드

3. **업로드 폴더 생성**
   ```bash
   # cPanel 파일 매니저에서 다음 폴더 생성
   api/uploads
   # 권한을 755로 설정
   ```

#### B. 새로 설치하는 경우
- 업데이트된 설치 패키지 사용 (모든 수정사항 포함)

### 3. 주요 수정사항

#### 백엔드 API 추가
- `POST /api/admin/books` - 관리자 직접 도서 입력
- `POST /api/admin/books/upload` - 파일 업로드
- `GET /api/admin/books` - 관리자 도서 목록 (비공개 포함)
- `PUT /api/admin/books/<id>` - 도서 수정
- `DELETE /api/admin/books/<id>` - 도서 삭제

#### 데이터베이스 스키마 개선
- `file_path`, `file_type`, `file_size`, `uploaded_by` 필드 추가
- 외래키 제약조건 추가
- 성능 향상을 위한 인덱스 추가

### 4. 기능 개선사항

#### ✅ 해결된 문제들
1. **도서 목록 표시 문제**
   - 관리자가 입력한 도서가 `is_public=True`로 기본 설정
   - 전체 도서 목록 API에서 정상적으로 표시

2. **파일 업로드 오류**
   - 적절한 파일 검증 및 오류 처리
   - 안전한 파일명 생성 (UUID 사용)
   - 업로드 폴더 자동 생성

3. **권한 관리**
   - JWT 토큰 기반 관리자 인증
   - 관리자만 업로드 및 수정 가능

#### 🔧 추가된 기능들
- 한국어 파일명 지원 (UTF-8, CP949 인코딩)
- 다양한 파일 형식 지원 (TXT, PDF, EPUB, DOC, DOCX, RTF)
- 파일 크기 제한 (16MB)
- 자동 텍스트 추출 (TXT, RTF 파일)

### 5. 테스트 방법

#### 관리자 로그인
- 사용자명: `admin`
- 비밀번호: `admin123`

#### 직접 입력 테스트
1. 관리자 패널 → "새 도서 추가"
2. 필수 정보 입력 (제목, 저자)
3. 저장 후 전체 도서목록에서 확인

#### 파일 업로드 테스트
1. 관리자 패널 → "파일 업로드"
2. 지원 형식의 파일 선택
3. 메타정보 입력
4. 업로드 후 도서목록에서 확인

### 6. 문제 해결

#### 파일 업로드 경로 설정
현재 설정: `/home/계정명/public_html/api/uploads`

실제 호스팅 계정에 맞게 수정하세요:
```python
# app.py 파일에서 수정
app.config['UPLOAD_FOLDER'] = '/home/실제계정명/public_html/api/uploads'
```

#### 권한 문제
업로드 폴더의 권한이 755 이상인지 확인하세요.
