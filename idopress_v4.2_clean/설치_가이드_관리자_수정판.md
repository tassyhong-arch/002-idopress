## 🛠 설치 방법

### 1단계: 데이터베이스 설정

#### A. cPanel → phpMySQL 접속
1. cPanel 로그인
2. "phpMyAdmin" 클릭
3. 좌측에서 `idopress` 데이터베이스 선택

#### B. 테이블 생성
`database_setup.sql` 파일의 내용을 복사해서 실행:
```sql
-- 이 파일의 전체 내용을 phpMyAdmin의 SQL 탭에 붙여넣고 실행
```

### 2단계: 백엔드 파일 업로드

#### A. Python App 생성
1. cPanel → "Setup Python App"
2. "CREATE APPLICATION" 클릭
3. 설정:
   - Python version: **3.9** 이상
   - Application root: **api**
   - Application URL: **api**
   - Application startup file: **app.py**
   - Application Entry point: **application**

#### B. 파일 업로드
1. cPanel → File Manager
2. `public_html/api/` 폴더에 다음 파일들 업로드:
   - `app.py` (수정된 버전)
   - `requirements.txt`

#### C. 의존성 설치
1. Python App 관리 페이지에서 "Run pip install" 클릭
2. 또는 터미널에서:
```bash
cd ~/public_html/api
pip install -r requirements.txt
```

#### D. 업로드 폴더 생성
1. File Manager에서 `public_html/api/uploads` 폴더 생성
2. 폴더 권한을 **755**로 설정

#### E. 설정 파일 수정
`app.py` 파일에서 업로드 경로를 실제 계정명으로 수정:
```python
app.config['UPLOAD_FOLDER'] = '/home/실제계정명/public_html/api/uploads'
```

### 3단계: 프론트엔드 설정

#### A. 정적 파일 업로드
1. `frontend_static.tar.gz` 압축 해제
2. 모든 파일을 `public_html/` 루트에 업로드

#### B. API 주소 설정
`js/main.js` 파일에서 API URL 수정:
```javascript
const API_BASE_URL = 'https://yourdomain.com/api';
```

### 4단계: 기존 사이트 업데이트 (기존 설치가 있는 경우)

#### A. 데이터베이스 마이그레이션
`database_migration.sql` 파일의 내용을 phpMyAdmin에서 실행

#### B. Flask 파일 교체
기존 `app.py`를 새 버전으로 교체

## ❗ 문제 해결

### 업로드 폴더 경로 오류
`app.py` 파일의 업로드 경로를 정확한 계정명으로 수정:
```python
app.config['UPLOAD_FOLDER'] = '/home/실제계정명/public_html/api/uploads'
```

### 권한 오류
1. `uploads` 폴더 권한을 755로 설정
2. cPanel File Manager → 폴더 우클릭 → Permissions → 755

### 데이터베이스 연결 오류
- MySQL 사용자명과 비밀번호 확인
- 데이터베이스명이 `idopress`인지 확인

### CORS 오류
- API URL이 올바른지 확인
- HTTPS 사용 권장

## 🎯 주요 API 엔드포인트

### 기존 API (변경 없음)
- `GET /api/health` - 서버 상태 확인
- `GET /api/books` - 도서 목록 조회
- `GET /api/books/<id>` - 특정 도서 조회
- `GET /api/books/genres` - 장르 목록
- `POST /api/admin/login` - 관리자 로그인

### 새로 추가된 API
- `GET /api/admin/books` - 관리자 도서 목록 (비공개 포함)
- `POST /api/admin/books` - **새 도서 직접 입력** ✨
- `POST /api/admin/books/upload` - **파일 업로드** ✨
- `PUT /api/admin/books/<id>` - 도서 수정
- `DELETE /api/admin/books/<id>` - 도서 삭제
