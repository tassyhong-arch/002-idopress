# 🚀 후이즈 호스팅 완전 자동 설치 가이드

## 📋 설치 순서 (코딩 지식 불필요!)

### 1️⃣ **기존 파일 전체 삭제**
- FTP에서 `public_html` 폴더의 **모든 파일 삭제**
- 완전히 비워주세요

### 2️⃣ **새 파일 업로드**
- 이 압축파일을 풀어서 나온 **모든 파일과 폴더**를 `public_html`에 업로드
- 업로드 후 구조:
```
public_html/
├── index.html              ← 메인 페이지
├── assets/                 ← CSS, JS 파일들  
├── api/                    ← 백엔드 API
│   ├── app.py
│   ├── requirements.txt
│   ├── .env
│   └── uploads/
├── .htaccess              ← 중요! 반드시 업로드
└── database_setup.sql     ← 데이터베이스 설정용
```

### 3️⃣ **cPanel에서 데이터베이스 생성**

#### A. MySQL 데이터베이스 만들기
1. **후이즈 cPanel 로그인** → **데이터베이스** → **MySQL 데이터베이스**
2. **새 데이터베이스 생성**:
   - 데이터베이스 이름: `idopress`
   - **데이터베이스 생성** 클릭

#### B. 데이터베이스 사용자 생성
1. **MySQL 사용자** 섹션에서:
   - 사용자명: `idopress_user`
   - 비밀번호: `idopress123` (또는 원하는 비밀번호)
   - **사용자 생성** 클릭

#### C. 사용자를 데이터베이스에 연결
1. **데이터베이스에 사용자 추가** 섹션에서:
   - 사용자: `idopress_user` 선택
   - 데이터베이스: `idopress` 선택  
   - **추가** 클릭
2. **모든 권한** 체크하고 **변경사항 적용**

### 4️⃣ **데이터베이스 테이블 생성**

#### A. phpMyAdmin 접속
1. **cPanel** → **데이터베이스** → **phpMyAdmin** 클릭
2. 왼쪽에서 `idopress` 데이터베이스 선택

#### B. SQL 실행
1. 상단의 **SQL** 탭 클릭
2. `database_setup.sql` 파일을 열어서 **전체 내용 복사**
3. phpMyAdmin의 SQL 창에 **붙여넣기**
4. **실행** 버튼 클릭
5. 성공 메시지 확인: "✅ 데이터베이스 설정이 완료되었습니다!"

### 5️⃣ **Python 앱 설정**

#### A. Python 앱 생성
1. **cPanel** → **소프트웨어** → **Python App** 클릭
2. **애플리케이션 생성**:
   - **Python version**: 3.8 또는 3.9 선택
   - **Application root**: `api` 입력
   - **Application URL**: 비워두기 (또는 `api`)
   - **Application startup file**: `app.py` 입력
3. **CREATE** 클릭

#### B. Python 패키지 설치
1. 방금 만든 Python 앱 옆의 **연필 아이콘** 클릭 (편집)
2. **패키지 설치** 섹션에서 다음 패키지들을 **하나씩** 설치:
   ```
   Flask==2.3.2
   Flask-SQLAlchemy==3.0.5
   Flask-JWT-Extended==4.5.2
   Flask-CORS==4.0.0
   PyMySQL==1.1.0
   Werkzeug==2.3.6
   ```
3. 각 패키지를 입력하고 **설치** 버튼 클릭
4. 모든 패키지 설치 완료까지 기다리기

### 6️⃣ **환경 설정 수정 (중요!)**

비밀번호를 다르게 설정했다면:
1. **cPanel 파일 매니저** → `public_html/api/.env` 파일 편집
2. 첫 번째 줄을 본인의 정보로 수정:
   ```
   DATABASE_URL=mysql://idopress_user:실제비밀번호@localhost/idopress
   ```

### 7️⃣ **테스트 및 완료**

#### A. 웹사이트 확인
1. **https://도메인.co.kr/** 접속 → 메인 페이지 확인
2. **https://도메인.co.kr/api/health** 접속 → API 상태 확인

#### B. 검색 기능 테스트
1. 메인 페이지에서 검색창에 "춘향" 입력 후 검색
2. 장르 버튼 ("문학", "역사") 클릭 테스트
3. 페이지 하단의 페이지 번호 클릭 테스트

## ✅ 성공 기준

모든 것이 정상 작동하면:
- ✅ 메인 페이지 로딩
- ✅ 검색 기능 작동 ("춘향", "홍길동" 등)
- ✅ 장르 분류 버튼 작동
- ✅ 도서 목록 표시
- ✅ 관리자 로그인 (ID: admin, 비밀번호: admin123)

## 🆘 문제 해결

### 문제 1: 500 에러가 계속 날 때
- Python 패키지 설치를 다시 확인
- cPanel 에러 로그 확인

### 문제 2: 데이터베이스 연결 오류
- MySQL 사용자명/비밀번호 다시 확인
- `.env` 파일의 DATABASE_URL 수정

### 문제 3: API가 404 에러
- `.htaccess` 파일이 업로드되었는지 확인
- Python 앱이 올바르게 생성되었는지 확인
