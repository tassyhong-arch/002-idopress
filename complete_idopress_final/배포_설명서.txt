└── *.conf                # 서버 설정 파일

🚀 웹서버 배포 방법:

1. Apache 서버:
   - 모든 파일을 document root (예: /var/www/html/)에 업로드
   - .htaccess 설정: 
     RewriteEngine On
     RewriteCond %{REQUEST_FILENAME} !-f
     RewriteCond %{REQUEST_FILENAME} !-d
     RewriteRule . /index.html [L]

2. Nginx 서버:
   - 모든 파일을 웹 루트에 업로드
   - nginx.conf에 다음 추가:
     location / {
         try_files $uri $uri/ /index.html;
     }

3. 단순 테스트:
   python3 -m http.server 80

⚠️  중요사항:
1. CSS/JS 파일 경로가 절대경로(/)로 설정되어 있음
2. 서버의 document root에 직접 업로드해야 함
3. 하위 디렉토리에 설치할 경우 index.html 수정 필요

🔧 문제 해결:
- CSS가 안 보이면: assets/ 폴더 권한 확인 (chmod 755)
- 흰 화면이면: 브라우저 개발자 도구에서 콘솔 오류 확인
- 404 오류: 웹서버 rewrite 규칙 확인
