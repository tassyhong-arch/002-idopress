# 🔧 도서 업로드 오류 해결 가이드

## 📋 문제 상황
**"업로드 실패: 정의되지 않음"** 오류가 발생하는 문제

## 🔍 원인 분석

### 일반적인 원인들:
1. **API 서버 연결 문제**: 백엔드가 실행되지 않음
2. **JWT 토큰 문제**: 관리자 인증이 만료되거나 잘못됨
3. **필드 유효성 검사 실패**: 필수 필드가 비어있음
4. **서버 내부 오류**: 데이터베이스나 파일 시스템 문제
5. **CORS 문제**: 브라우저에서 API 요청이 차단됨

## 🛠 즉시 확인할 수 있는 해결 방법

### 1단계: 기본 확인 사항

#### A. API 서버 상태 확인
브라우저에서 다음 주소로 접속:
```
https://yourdomain.com/api/health
```

**정상 응답:**
```json
{
  "status": "healthy",
  "message": "이도출판 디지털 장서각 API 서버 정상 작동"
}
```

#### B. 브라우저 개발자 도구 확인
1. **F12** 키로 개발자 도구 열기
2. **Console** 탭에서 오류 메시지 확인
3. **Network** 탭에서 API 요청 상태 확인

### 2단계: 테스트 페이지 사용

#### A. 간단한 업로드 테스트
`test_upload.html` 파일을 웹사이트에 업로드하고 접속:
```
https://yourdomain.com/test_upload.html
```

#### B. 단계별 테스트
1. **로그인 테스트**: admin / admin123
2. **간단한 데이터로 업로드 테스트**
3. **오류 메시지 확인**

### 3단계: 관리자 패널에서 재시도

#### A. 다음 순서로 시도:
1. **로그아웃 후 재로그인**
2. **브라우저 캐시 삭제** (Ctrl+Shift+Delete)
3. **필수 필드만 간단히 입력**:
   - 제목: "테스트"
   - 저자: "테스트"
   - 장르: 드롭다운에서 선택
4. **다른 필드는 비워두고 업로드**

## 🔧 문제별 상세 해결 방법

### 🚨 A. "업로드 실패: 정의되지 않음" 오류

**원인**: JavaScript에서 API 응답을 제대로 파싱하지 못함

**해결책**:
1. **F12 → Console**에서 자세한 오류 확인
2. **Network 탭**에서 실제 API 응답 확인
3. 관리자 패널 **새로고침 후 재로그인**

### 🚨 B. "제목과 저자는 필수입니다" 오류

**원인**: 필수 필드가 비어있거나 공백만 있음

**해결책**:
```
✅ 제목: 최소 1글자 이상 입력
✅ 저자: 최소 1글자 이상 입력
⚠️ 앞뒤 공백 제거 확인
```

### 🚨 C. "관리자 권한이 필요합니다" 오류

**원인**: JWT 토큰이 만료되거나 유효하지 않음

**해결책**:
1. **로그아웃** 버튼 클릭
2. **브라우저 저장소 초기화**:
   - F12 → Application → Local Storage → 도메인 → Clear All
3. **페이지 새로고침** 후 재로그인

### 🚨 D. "서버 내부 오류" (500 Error)

**원인**: 백엔드 서버나 데이터베이스 문제

**해결책**:
1. **cPanel → Python Apps**에서 앱 재시작
2. **cPanel → Errors**에서 로그 확인
3. **데이터베이스 연결 확인**

### 🚨 E. "네트워크 오류" (fetch failed)

**원인**: API 서버가 실행되지 않거나 URL이 잘못됨

**해결책**:
1. **Python App 상태 확인**: cPanel → Python Apps
2. **URL 확인**: https://yourdomain.com/api/health 접속 테스트
3. **HTTPS 설정 확인**: SSL 인증서 유효성

## 📋 단계별 문제 해결 체크리스트

### ✅ 1단계: 기본 확인
- [ ] API 서버 실행 상태 (cPanel → Python Apps)
- [ ] 브라우저 개발자 도구에서 오류 메시지 확인
- [ ] 필수 필드 (제목, 저자) 입력 확인

### ✅ 2단계: 인증 확인  
- [ ] 관리자 로그아웃 후 재로그인
- [ ] 브라우저 저장소 초기화
- [ ] test_upload.html로 별도 로그인 테스트

### ✅ 3단계: 서버 확인
- [ ] /api/health 접속으로 서버 상태 확인
- [ ] cPanel Errors 로그 확인
- [ ] 데이터베이스 연결 상태 확인

### ✅ 4단계: 데이터 확인
- [ ] 간단한 데이터로 테스트 (제목: "테스트", 저자: "테스트")
- [ ] 특수문자나 긴 텍스트 제거
- [ ] 파일 업로드 대신 직접 입력으로 시도

## 🚀 빠른 해결 방법

### 대부분의 경우 이 방법으로 해결됩니다:

1. **브라우저 새로고침** (Ctrl+F5)
2. **관리자 로그아웃 → 재로그인**
3. **최소한의 정보로 테스트**:
   ```
   제목: 테스트
   저자: 테스트  
   장르: 문학 (드롭다운에서 선택)
   소개: 테스트입니다
   ```
4. **"직접 입력" 탭에서 업로드**

### 긴급 상황 시:
- `test_upload.html`을 사용한 별도 업로드 테스트
- cPanel에서 Python App 재시작
- 데이터베이스에서 직접 INSERT 쿼리 실행
